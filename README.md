
# Placement Management Portal

A modern, responsive dashboard web application built with React, Vite, TypeScript, and shadcn/ui.

## Features

* **Agent Activity Feed:** Real-time monitoring and tracking of automated agent tasks and operational logs.
* **Interactive Dashboard UI:** Clean, component-driven interface built for high-visibility management and control.
* **TypeScript & Vite:** High-performance development workflow with strict type safety.

## Tech Stack

* **Framework:** React (with Vite)
* **Language:** TypeScript
* **UI Components:** shadcn/ui & Tailwind CSS
* **Package Manager:** Bun

## Getting Started

Follow these instructions to set up the project locally on your machine.

### Prerequisites

Make sure you have [Bun](https://bun.sh/) installed.

### Installation

1. Clone the repository:
```bash
git clone https://github.com/your-username/placement_management_portal.git

```


2. Navigate to the project directory:
```bash
cd placement_management_portal

```


3. Install dependencies:
```bash
bun install

```


4. Start the development server:
```bash
bun run dev

```
